# Skill sources UI QA artifacts

Generated by the SPA E2E spec `e2e/spa-skill-sources.spec.ts` against the deterministic fixture
server (`e2e/support/server.ts`). The fixture seeds a fake skills hub and synthetic skill data only;
no deployment host, real project, real token, or real session appears here.

## Fixture data

- Source `e2e-skills` ("E2E Skills") at the reserved fixture endpoint `https://skills-hub.e2e.test`,
  with the write-only sentinel token `e2e-skill-source-token-sentinel`.
- One active snapshot at revision `e2e-rev-1` containing `e2e-external-skill`:
  `SKILL.md`, `references/guide.md` (text preview), and `assets/logo.bin` (binary metadata only).
- The fake hub ignores its host, serves the manifest/files, and supports revision and skill changes
  through `fixture.skillHub` in the fixture process.

## Commands

```bash
npm run build
PLAYWRIGHT_CHROMIUM=/usr/bin/chromium npx playwright test e2e/spa-skill-sources.spec.ts --project=spa
PLAYWRIGHT_CHROMIUM=/usr/bin/chromium npx playwright test e2e/spa-skills.spec.ts e2e/spa-settings.spec.ts --project=spa
```

## Scenarios

| Test | Covers |
| --- | --- |
| capture | Settings source list, source drawer, add-source dialog, Skills external row and External filter, and the external skill drawer at 390/1440 in dark and light. |
| settings list | Seeded source name/slug, `Ready` chip, short revision, skill count and total bytes, endpoint host, and no token sentinel in the DOM. |
| deep link | `/settings#settings-sources` selects the console rail item and shows the pane; the old `#settings-skill-sources` hash maps to the same pane. |
| sync/check | `Sync now` success toast plus `Check for updates` inline `Up to date · e2e-rev-1` result. |
| pin/disable/enable | Pin badge and `Unpin` primary action, unpin, disable confirmation, `Disabled` chip, `Enable`, and the follow-up sync back to `Ready`. |
| token | Replace-token dialog with a new sentinel, assertion that neither sentinel is in `page.content()`, then Clear token shows `Not set`. |
| create/delete | Add-source dialog against the fake hub, first sync becomes `Ready`, typed-slug delete posts `{ "hard": true }`, and the row disappears. |
| external inventory | `[data-skill-mode="external"]` row shows Source/Read-only and source name, has no `/skills/null` href, External filter isolates it, the drawer previews a text file, and a binary file shows metadata only. |
