# Journal - core coordinator

## Stage 1 - State store, registry, CLI (done)

- Scope: persistence + discovery + CLI. Non-goals: spawning, queue, MCP, HTTP.
- Delivered:
  - `src/store/` - SQLite driver (`better-sqlite3`), pragmas (WAL, `synchronous=NORMAL`,
    `busy_timeout=5000`, `foreign_keys=ON`), forward-only migrations (`schema_migrations` with
    checksum), full schema per design §6.
  - `src/registry/` - `discoverProject` (walk up, validate) and idempotent `registerProject`.
  - `src/runtime/` - state-home and path resolution under `XDG_STATE_HOME`.
  - CLI: `hanse init [dir]`, `hanse status [dir]`.
- Decisions:
  - Driver `better-sqlite3` (rejected `node:sqlite`: experimental, needs Node 22.5+).
  - One global coordinator DB at `$XDG_STATE_HOME/hanse/coordinator.db`; per-instance dirs keyed by
    project id.
  - Application id = `<projectId>:<appKey>`; `appKey` = `basename(path)` until the app's own
    `.hanse/app.yaml` is read (Stage 2+).
  - `src/registry/` supersedes `src/coordinator/registry.ts` (removed).
- Verification: `lint`, `typecheck`, `build` clean; 28 tests pass (store, registry, commands, schema,
  config, instance, cli). Smoke: `init` scaffolds the manifest; `status` registers the project and
  creates the DB.
- Deviation: **Stage 0.5 (vertical spike) deferred.** It needs a live authenticated `opencode` and
  affects Stage 5 (delivery), not Stage 1. Recorded as an open item to run before Stage 5.
- Artifacts: `src/store/*`, `src/registry/index.ts`, `src/runtime/*`, `src/cli/*`, tests.
- Next: Stage 0.5 spike, then Stage 2 (launcher).
