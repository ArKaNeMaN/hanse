# Release 0.1.0

First pre-alpha release of the hanse coordinator core.

## Included (stages 0-7)

- `.hanse/project.yaml` / `.hanse/app.yaml` manifest schemas (zod).
- SQLite state store (`better-sqlite3`, WAL, forward-only migrations).
- Project/application registry and runtime layout.
- CLI: `init`, `status`.
- Per-application `opencode` launcher (isolated XDG env, `OPENCODE_CONFIG_CONTENT` overlay).
- Durable handoff state machine and cross-process writer lock.
- Principals/authn and human-gated approvals.
- Coordinator service and MCP tools (`request_sibling_change`, `list_apps`, `handoff_status`,
  `deliver_handoff`).
- HTTP API and a minimal server-rendered dashboard.
- Encrypted secret store and a git credential helper.
- Structured logging.

## Not yet

- Stage 0.5 vertical spike against a live `opencode` (verify steer/event capabilities).
- Wiring the HTTP server and MCP server into the CLI entrypoint.
- End-to-end delivery of a handoff into a live `opencode` operator session.
- Web UI auth flow beyond bearer tokens.

## Verification

`npm run lint && npm run typecheck && npm test && npm run build` (all green).
